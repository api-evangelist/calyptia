# Calyptia

> Calyptia builds Calyptia Cloud (Telemetry Pipeline) and Calyptia Core — a management
> plane for Fluent Bit, the open-source telemetry agent for logs, metrics and traces.
> Calyptia was acquired by Chronosphere in 2024; calyptia.com now redirects to
> chronosphere.io, but the Calyptia Cloud API (cloud-api.calyptia.com), its API
> reference, status page and CLI remain live and actively released.

## API
- [Calyptia Cloud API (OpenAPI 3.0.4)](openapi/calyptia-cloud-openapi-original.yml): 183 operations across projects, tokens, core instances (aggregators), pipelines, fleets, agents, processing rules, trace sessions and metrics. Base URL https://cloud-api.calyptia.com.
- [API Reference](https://docs.calyptia.com/docs/calyptia-cloud-api/api-reference)

## Auth
- Project API token via `X-Project-Token` header (from core.calyptia.com / project Settings)
- User JWT bearer token
- OAuth2 (Auth0, sso.calyptia.com): clientCredentials + authorizationCode
- [Authentication profile](authentication/calyptia-authentication.yml)
- [OAuth / OIDC scopes](scopes/calyptia-scopes.yml)
