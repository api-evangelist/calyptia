Calyptia builds Calyptia Cloud (Telemetry Pipeline) and Calyptia Core, a commercial management plane for Fluent Bit — the widely deployed open-source agent and processor for logs, metrics and traces. The Calyptia Cloud API lets teams create and operate core instances, telemetry pipelines, agent fleets, processing rules and live trace sessions programmatically, authenticated with project API tokens. Calyptia was founded by the creators of Fluent Bit and Fluentd and was acquired by Chronosphere in 2024; calyptia.com and the product docs now route to chronosphere.io, but the Calyptia Cloud API (cloud-api.calyptia.com), its API reference, status page, Go client and the `calyptia` CLI remain live and actively released. Backed by Sierra Ventures.

**Areas:** Company · Infrastructure · Observability · Telemetry · Logging · Fluent Bit · Data Pipeline · Kubernetes · DevOps

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).
